# Criar conta — UC11, Aula 1 · 08/09/2026

**Dê dois cliques no `Aula01Login.sln`.** É o único arquivo que você abre.

| O que tem aqui | |
|:--|:--|
| `Aula01Login.sln` | os três projetos, já ligados um no outro |
| `login-tela/` | a JANELA — Windows Forms, igual aos da UC12 |
| `login-defeituoso/` | o `Cadastro.cs`, que é o que você vai testar |
| `login-testes/` | os 18 casos: **1 pronto e 17 para você escrever** |
| `LEIA-ME.md` | **leia este** — é a ordem da noite inteira |
| `apostila-teste-login-inicio.pdf` | **a apostila, 65 páginas** — a referência da UC inteira |

Esta pasta é o **começo**. No fim da noite ela vai ter os 18 testes
escritos, e dois ou três defeitos consertados.

> **A apostila não tem uma linha de C#**, e é de propósito: o código vai
> para o QUADRO, e traduzir do Portugol dela para o C# do quadro é metade
> do exercício.

> Apertou F5 e abriu uma janela preta de console? O Visual Studio escolheu o
> projeto errado. Botão direito em **`LoginTela`** → **Definir como Projeto de
> Inicialização**, e F5 de novo.
